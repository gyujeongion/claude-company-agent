# 40_ASSETS — 브랜드 · 서식 · 템플릿

로고, 문서 서식, 계약 템플릿, 제안서 틀, 프레젠테이션 마스터.

## 구조 (필요한 것만 만드세요)

```
40_ASSETS/
├── brand/       로고·컬러·폰트·사용 규칙
├── templates/   계약서·제안서·견적서 틀
└── forms/       사내 양식
```

## 규칙

- **바이너리 원본 + 사용법 메모(.md)**를 한 쌍으로 둡니다. 메모 없는 템플릿은
  어떤 상황에 쓰는 건지 몰라서 안 쓰입니다.
- 계약 템플릿을 쓸 때 에이전트는 **빈칸을 임의로 채우지 않습니다.**
  채울 값이 없으면 `{{...}}`로 남기고 사용자에게 묻습니다.
- 로고·브랜드 자산은 사용 규칙(여백·변형 금지 등)을 함께 적습니다.
