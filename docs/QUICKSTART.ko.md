# 5분 시작 (직원용)

> 개발 지식 없어도 됩니다. 아래를 그대로 복사해서 터미널에 붙여넣으세요.

## 1. 받기

```bash
git clone <회사에서 받은 주소> ~/AI/company
cd ~/AI/company
bash tools/bootstrap.sh
```

> **레포 주소는 회사에서 받습니다.** 못 받았으면 여기서 멈추고 담당자에게 요청하세요.
>
> **에러가 나면 그냥 그 화면을 통째로 복사해서 클로드에게 붙여넣으세요.**
> "이거 왜 안 돼?"라고 물으면 됩니다. 직접 해결하려 하지 않아도 됩니다.
> 그래도 안 되면 담당자에게 그 화면을 그대로 보여주세요.

## 2. 열기

```bash
cd ~/AI/company
claude
```

## 3. 세팅

클로드에게 그대로 입력:

```
세팅해줘
```

5분짜리 인터뷰가 시작됩니다. 본인 직무와 일하는 방식을 물어봅니다.
**개인 정보 부분은 회사에 올라가지 않습니다** — 안 쓰고 싶으면 건너뛰어도 됩니다.

## 4. 써보기

세팅이 끝나면 이런 걸 물어보면 됩니다.

- "우리 회사가 하는 일 정리해줘"
- "이 메일 초안 잡아줘. 받는 사람은 거래처야"
- "작년 OO 관련 자료 있어?"
- "이 문서 요약해줘" (파일 경로를 주면 됨)

개인 용도로도 씁니다:
- "이번 주 할 일 정리해줘"
- "이 영어 메일 뭐라고 하는 거야"

## 알아둘 것

| | |
|---|---|
| 개인 정보 | `90_ME/` 폴더에 저장, 회사에 안 올라감 |
| 회사 자료 업데이트 | `git pull` 하면 최신으로. 내 파일은 안 지워짐 |
| 모르면 | 클로드에게 "이 워크스페이스 어떻게 쓰는 거야?" 라고 물어보면 됨 |
| 발송·게시 | AI는 초안까지만. 보내는 건 본인이 |

## 안 되는 것

- 비밀번호·API 키를 대화에 붙여넣기 (차단됩니다)
- 회사 사실을 AI가 지어낸 걸 그대로 쓰기 — **근거 없는 답은 "확인 필요"라고
  나옵니다.** 그렇게 안 나오고 술술 답하는데 이상하면 출처를 물어보세요.
