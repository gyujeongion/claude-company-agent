# 외부발송 체크

status: active
소유: 전원 · 회사 밖으로 나가는 모든 산출물에 적용

## 언제 쓰나

메일 발송, 거래처 전달, 공지·보도자료, SNS 게시, 외부 공유 문서.
`boundary_gate.py` 훅이 관련 키워드에서 이 문서를 자동 상기시킵니다.

## 체크리스트

**개인정보**
- [ ] 이름 외 연락처·주소·주민번호·계좌가 들어있지 않은가
- [ ] 수신자가 봐도 되는 사람 정보만 있는가 (제3자 정보 혼입 없음)

**내부 정보**
- [ ] 내부 수치(원가·마진·정산·급여)가 그대로 노출되지 않는가
- [ ] 미확정 일정·금액을 확정처럼 쓰지 않았는가
- [ ] 타사·타인에 대한 내부 평가가 남아있지 않은가

**작업 흔적**
- [ ] 초안 메모·주석·이전 버전 문구가 남아있지 않은가
- [ ] AI·모델명·내부 파일 경로·워크스페이스 구조가 노출되지 않는가
- [ ] 파일 메타데이터(작성자·수정이력)를 확인했는가

**톤·형식**
- [ ] `00_COMPANY/brand_voice.md`와 맞는가
- [ ] 우리가 결정할 수 없는 것을 약속하지 않았는가

**승인·발송**
- [ ] 이 건에 승인이 필요한지, 필요하면 받았는지 (본인이 판단)
- [ ] **발송 버튼은 사람이 누른다** — AI는 초안까지
