# 회사 자료 흡수

`docs/INGEST.md` 전체 절차를 따른다. 요약:

## 하지 말 것

- 원본 수정·이동 (기본은 복사)
- 물어보지 않고 전부 분류해서 들이밀기
- 시크릿 플래그 파일 적재
- 카드 없이 원본만 쌓기
- 판단 안 되는 파일 버리기 (→ `ingest/_UNSORTED/`)

## 순서

1. **스캔** — `python3 tools/ingest_scan.py <경로> ...`
2. **보고** — `ingest/_scan/REPORT.md` 읽고 전체 그림부터 사용자에게.
   모르는 폴더명은 뜻을 물어본다. 원본 폴더 구조가 이 회사의 실제 분류다.
3. **분류안** — `manifest.jsonl`을 200개씩 배치로 읽어 `ingest/plan.jsonl` 작성
4. **승인** — `--dry-run`으로 보여주고 확인받은 뒤 `ingest_apply.py` 실행
5. **카드** — `30_KNOWLEDGE/cards/`에 색인 카드 + `INDEX.md` 한 줄씩.
   전부 쓰지 말고 자주 쓰는 것·최근 1년·정확도 중요한 것 순으로.
6. **보고** — 적재/카드/미분류/skip 건수 + 시크릿 파일 위치 + 시험 질문 3개

## 목적지 판단표

| 성격 | 목적지 |
|---|---|
| 계약·정산·리서치·회의록·기획 | `30_KNOWLEDGE/{연도}/{분류}/` |
| 반복 절차·매뉴얼 | `20_PLAYBOOKS/` (재작성) |
| 로고·서식·템플릿 | `40_ASSETS/` |
| 진행 프로젝트 | `50_PROJECTS/{이름}/` |
| 끝난 것 | `80_ARCHIVE/` |
| 판단 불가 | `ingest/_UNSORTED/` |
| 시크릿 🔴 | skip + 위치만 보고 |
