# 60_SYSTEMS — 사내 툴 · 계정 · 자동화

우리가 뭘로 일하는지. 에이전트가 "어디에 있는 데이터인가"를 알기 위한 지도.

## 여기 적는 것

- 쓰는 서비스와 **각각 무슨 용도인지** (Slack·드라이브·회계·CRM·NAS 등)
- 어떤 데이터가 어디에 사는지
- 연결된 MCP 서버·자동화가 있으면 그 목록과 상태
- 접근 권한을 누가 주는지

## 여기 절대 안 적는 것

- 아이디·비밀번호·API 키·토큰 → `00_COMPANY/policy/security.md`
  (`secret_guard.py` 훅이 읽기를 차단합니다)

## 형식

```markdown
### {서비스명}
- 용도: 
- 여기 사는 데이터: 
- 접근 권한: {누구에게 요청}
- 에이전트 연동: {MCP 서버명 또는 없음}
- 주의: 
```
