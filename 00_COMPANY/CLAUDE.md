# 00_COMPANY — 회사 정본

전 직원 공통. 여기 있는 내용이 회사에 관한 **단일 진실**입니다.
다른 폴더와 충돌하면 여기가 이깁니다.

## 파일

| 파일 | 언제 여나 |
|---|---|
| `identity.md` | 회사가 뭐 하는 곳인지, 지금 뭘 중요하게 보는지 — 세션 시작 시 항상 |
| `brand_voice.md` | 외부에 나가는 글을 쓸 때 (메일·제안서·SNS·보도자료) |
| `glossary.md` | 모르는 내부 약칭·용어가 나올 때 — **추측하지 말고 여기 먼저** |
| `policy/ai_usage.md` | 모든 요청의 판단 게이트. 항상 적용 |
| `policy/security.md` | 파일·자격증명·민감정보를 다룰 때 |
| `policy/escalation.md` | "이거 내가 결정해도 되나" 싶을 때 |
| `policy/scope.md` | **다루지 않는 영역** (인사·급여·조직·직원 개인). 항상 적용 |

## 규칙

- **여기 없는 회사 사실은 지어내지 않습니다.** 모르면 모른다고 하고 **담당자에게
  확인하라고 안내**합니다. 사내 AI가 신뢰를 잃는 1번 경로가 "그럴듯한 회사 사실 창작"입니다.
- **여기는 실무 기준만 둡니다.** 조직도·결재선·인원·경영 현황 같은 운영 정보는
  넣지 않습니다. 업무를 하는 데 필요하지 않고, 유출됐을 때만 문제가 됩니다.
- 이 폴더의 내용을 바꾸는 것은 회사 정책 변경입니다. 사용자가 요청해도
  **누가 승인했는지 확인**하고, 변경 시 날짜와 근거를 남깁니다.
- **사람에 관한 정보를 두지 않습니다.** 실명 명단·직급·인원·조직도·연락처·급여·평가.
  이 레포는 전 직원이 공유하므로, 경로가 잘못 공유되면 전원이 봅니다.
- 인사·급여·근로계약·조직은 아예 다루지 않습니다 → `policy/scope.md`
- 내 담당자·사수가 누구인지는 **각자 `90_ME/`에** 적습니다 (로컬, 공유 안 됨).
