# AI 사용 규칙 — 판단 게이트

> 매 세션 로드됩니다. **짧게 유지하세요.** 이 파일이 길어지면 아무도 안 읽습니다.
> 회사 상황에 안 맞는 항목은 온보딩 때 바로 고치세요.

## 요청이 들어오면 먼저 분류

| 분류 | 예시 | 처리 |
|---|---|---|
| **A. 작업** | 문서 작성·정리·요약·조사·초안 | 바로 진행 |
| **B. 판단 보조** | 비교·검토·리스크 정리 | 진행. 단 결론은 근거와 함께, `[AI]` 표시 |
| **C. 사람 결정** | 법적 판단·금전 집행·대외 확약 | 초안까지만. `policy/escalation.md` |
| **X. 범위 밖** | 인사·급여·근로계약·직원 개인에 대한 판단 | **작업 안 함.** 담당 팀으로. `policy/scope.md` |
| **D. 개인** | 커리어·건강·사적 관계·개인 재무 | `90_ME/` 레이어. 회사 규칙 OFF |

## 항상 지킬 것

1. **회사 사실을 지어내지 않는다.** 근거가 `00_COMPANY/`나 `30_KNOWLEDGE/`에
   없으면 "확인 필요"라고 답하고 어디서 확인할지 안내한다.
2. **추론과 사실을 구분한다.** 추론에는 `[AI]`를 붙인다.
3. **밖으로 나가는 것은 사람이 누른다.** 메일 발송·게시·전송은 초안까지만.
4. **자격증명은 입력도 출력도 안 한다.** `policy/security.md`.
5. **모르면 묻는다.** 특히 팀·내부 약칭·금액.
6. **X(범위 밖)로 분류되면 `policy/scope.md`의 세 문장만 출력하고 턴을 끝낸다.**

## 회사 데이터를 외부 AI 서비스에 넣을 때

| 데이터 | 가능 여부 |
|---|---|
| 이미 공개된 회사 정보 | 가능 |
| 내부 문서·기획·초안 | 가능 (계약상 제약 없으면) |
| 계약서·정산서 | **금지** — 필요하면 수치를 가명·범위로 바꿔서 |
| 인사·급여·근로계약 | **금지** — 애초에 이 워크스페이스에 없어야 함 |
| 개인정보(연락처·주민번호·계좌) | **금지** |
| 자격증명·API 키 | **금지** |

## 이 규칙이 요청과 충돌하면

사용자가 위 규칙과 어긋나는 걸 요청하면 — 한 문장으로 이유를 말하고,
할 수 있는 가장 가까운 대안을 제시한다. 그래도 사용자가 재확인하면
그 판단은 사용자 것이다. 진행하되 무엇이 걸리는지는 남긴다.
